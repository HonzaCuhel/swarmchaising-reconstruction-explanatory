# Reconstruct the incident

Use the reading notes to write `reconstruction.md`: the assignment and environment, consequential actions, supported outcome and unresolved questions. Explain the incident in plain language.

Create an event DAG in `event-dag.md`. Choose events that help explain the incident, give them consistent identifiers and link them to supporting records. For each directed relationship, explain what connects the events and cite the evidence. Mark an uncertain connection as an inference. Time order alone does not establish a causal relationship.

Keep missing steps and conflicting evidence visible. A compact diagram and a short explanation are sufficient; use an interactive view only when requested. Check that the graph and written account agree with the reviewed sources.
