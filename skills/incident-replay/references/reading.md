# Read the records

Start `reading-notes.md` with the source names or links and the requested scope. Read the original records in order, in manageable chunks. Read relevant tool calls together with their recorded results.

Before opening the next chunk, add a concise note containing:

- The source range or record IDs reviewed.
- Actions, results and relevant statements, with source references.
- Actors and entities encountered.
- Missing information, contradictions or corrections.

Keep a short actors/entities list in the same file. Use consistent names without assuming two identities are the same. Record skipped or incomplete ranges so the notes accurately describe what was reviewed.

Preserve the difference between an attempted action, a claimed result and a result shown in the record. Note corrections and their sources. Keep the notes factual and brief.
